Card explanation editorこの札について　解説エディタ

Marked kana shown as

This is how the page looks in the app. The card at the top is only there so you know which card you are writing about. Dashed boxes mark parts of the real page that are left out here. Your text starts under the “About the poem” heading. A dotted underline marks kana in { } (editor only).

How to write　書き方

Write plain text with a few marks. The phone on the left updates as you type. Leave a blank line between paragraphs.普通の文章に、いくつかの記号を足して書きます。段落の間は1行空けてください。

First line
Every file starts with a # heading. It gets the coloured marker. The words after | appear small beside it, in the other language. # 解説 | Explanationファイルの最初は必ず # の見出し。「 | 」の後ろは、もう一方の言語の小さな文字になります。
Headings
## Big heading ### Smaller #### Smallest
Bold and highlight
**bold** makes text heavy. *highlight* puts the card's colour behind it.**太字**　*マーカー*
Lists
- item gives a diamond. 1. item gives a number. Keep lists flat, with no lists inside lists.
Quote
> quoted words
Line
--- on its own line, with a blank line above it. (Right under a line of text it turns that text into a heading.)
Poem lines
A verse block shows poem lines with furigana. Write [漢字|かな], one poem line per line, and a full-width space (　) where the line may break. ```verse [秋|あき]の[田|た]の　かりほの[庵|いほ]の ```[漢字|かな] でふりがな。1行に1句、区切りは全角スペース。
Kana that can turn into romaji
Put kana in curly braces, as it is pronounced: The kimariji is {あきの}. Kana mode shows あきの and Romaji mode shows akino. Write {わ} for the particle は. Only the text inside { } changes. It works in headings, lists, quotes, bold and highlight, but not inside a verse block or inside [漢字|かな]. To show a real brace, write \{.ローマ字にしたいかなは { } で囲み、発音どおりに書きます。
Pictures
![caption](assets/pictures/name.png) alone on its line, with the caption under the picture. Use only letters, digits, - and _ in the file name. Pictures show at most 140 px tall. The image files must be sent to the developer together with the .md files.画像ファイルは .md と一緒に開発者へ送ってください。
Not supported
Tables, links, code, nested lists and HTML show as plain text or not at all. The check list under the editor tells you when something will not work.
File:

    Save each .md file under the same name in the folder shown above. Pictures are not inside the .md: send the image files to the developer as well. “Download all (.zip)” makes one zip with every draft in its folder, plus the pictures you added here. “Export JSON” and “Import JSON” move all your drafts to another computer.

    Card data (optional)　札のデータ

    Paste the file data.csv from github.com/StoneLabs/hyakuninissyu-csv to see each card's kimariji, poem and colour in the preview. It is saved in this browser. Without it everything else still works.
