===========================================================================
LICENSES FOR THE KIMARIJI VOICE CLIPS (assets/voice/kimariji/)
===========================================================================

The placeholder kimariji clips in assets/voice/kimariji/ were generated
offline with pyopenjtalk 0.4.1 (https://github.com/r9y9/pyopenjtalk), a
Python wrapper around Open JTalk and HTS Engine API, using Open JTalk's
bundled UTF-8 dictionary and its default voice model, "Mei". This file
reproduces, in full and unmodified, every license that covers those
components, copied verbatim from the files shipped inside the pyopenjtalk
PyPI package (and the dictionary archive it downloads from the Open JTalk
project on first use). See scripts/kimariji_voice.py for how the clips are
generated.

Five license texts follow:
  1. pyopenjtalk (the Python wrapper) - MIT License
  2. Open JTalk (the text-analysis/synthesis engine) - BSD-style license
  3. hts_engine API (the HMM speech-synthesis engine Open JTalk embeds) -
     BSD-style license
  4. The bundled UTF-8 dictionary (built from the NAIST Japanese
     Dictionary and UniDic) - BSD-style license
  5. The default voice model "Mei" (mei_normal.htsvoice) - Creative
     Commons Attribution 3.0
