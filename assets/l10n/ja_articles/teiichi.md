強い選手は、毎試合、札を同じ場所に並べています。そのわけと、自分だけの並べ方の作り方を紹介します。

# 定位置ってなに？

自陣の25枚は、どこに並べてもかまいません。それでも多くの選手は、どの札をどこに置くかを前もって決めて、毎試合そのとおりに並べます。これが定位置（ていいち）です。

自陣は3段に分かれています。中央の線に近いほうから上段（じょうだん）、中段（ちゅうだん）、いちばん手前が下段（げだん）です。札は左右ふたつのかたまりに分けて置くのが一般的です。

定位置には、よいことが二つあります。まず、自陣の札の場所をいちいち覚えなくてすみます。そして、それぞれの場所への動きを手が覚えるので、札が読まれると自然に手が出ます。

# 暗記時間が楽になる

試合の前には15分の暗記時間があり、50枚すべての場所を覚えます。敵陣は毎試合変わりますが、自陣は毎回同じにできます。定位置がしっかりしていれば、並べ終えた時点で自陣はもう覚えています。

よい定位置なら、並べるのも速くなります。考えこまずに、25枚を1分以内で並べられます。そうすれば、15分はまるごと敵陣に使えます。同じ音で始まる札ごとにまとめて覚え、目を閉じて確かめ、覚えきれなかった札を見直しましょう。

# 基本の置き方

多くの選手が、次のような置き方から始めます。

- **一字決まり**（む・す・め・ふ・さ・ほ・せ）は1音目で取れるので、手にいちばん近い下段に置く人が多いです。相手に一か所だけをねらわれないよう、左右に分けて置く人もいます。
- **決まり字の長い札**は取りに行くまでに時間の余裕があるので、外側の端に置く人が多いです。いちばん長いのは「あさぼらけ」「きみがため」「わたのはら」で始まる6枚の大山札（おおやまふだ）で、6音目まで聞かないと決まりません。待つあいだ囲って守りやすいよう、利き手側に置く人が多いです。
- **得意札**も、利き手側に置くことがよくあります。

# 友札の置き方

友札（ともふだ）は、「なげき」と「なげけ」のように、同じ音で始まる札です。置き方について、いちばん意見が分かれるところです。

- **分ける。** 左右に一枚ずつなど、離して置く人がいます。くっついていると、相手は一度の動きで両方をねらえますし、並べ方も覚えられやすくなるからです。
- **まとめる。** となり合わせに置く人もいます。覚えやすく、最初の音で動き出して、決まり字が聞こえたところで正しいほうを取れます。ただ、相手も同じ場所へ早めに動けてしまいます。
- **その中間。** 一部の友札だけを分けて、自陣を覚えきれなくならない程度にとどめる人も多いです。

<!-- picture: 自陣が二つ並んでいる。左の自陣では「なげ」の2枚がとなり合い、右の自陣では左右のかたまりに1枚ずつ。どちらも2枚に同じ色の印。札の文字はかな | caption: 左はまとめた形。自分にも相手にも覚えやすい。右は分けた形。どちらにも覚えにくくなります。 -->

**はじめのうちは：** まずは友札をまとめて置き、並べ方に慣れてきたら少しずつ分けてみましょう。

>{.tobi pose=waving} ボクの友札は、いま反対側にいるんだ。ときどき手をふり合ってるよ。

# 左右と段の枚数

**左右。** 利き手のほうが速いので、利き手側に多めに置く人がたくさんいます。いっぽうで、どちらにも同じように動けるよう、左右をほぼ同じ枚数にする人もいます。

**段。** 上段は自分から遠く、相手に近い段です。そのため上段をいちばん少なく、下段をいちばん多くする人がほとんどです。中段を少なくする人もいます。相手は覚えにくくなりますが、そのぶん上段の札が増え、自分では取りにくくなります。

**中央のあき。** 左右のかたまりのあいだは、ふつう空いています。この上段の真ん中に1、2枚置く人もいます。たとえば、友札の片方をここに置いて分ける形です。ぽつんと離れた札は見つけやすい反面、どちらのかたまりからも遠いので、戻りにくくなります。

**はじめのうちは：** 左右はほぼ同じ枚数に、上段は少なめに。バランスはあとから変えれば大丈夫です。

# 札が動いたら

試合中、自陣は変わっていきます。敵陣の札を取ったら、自陣の札を1枚相手に送ります。これが送り札（おくりふだ）です。相手に自陣の札を取られたら、相手から1枚送られてきます。つまり定位置は、自陣の始まりの形であって、最後までそのままではありません。次の二つを決めておくと安心です。

- **送られた札の置き場所。** 札ごとに二つ目の置き場所を考えておく人や、「送られた札はここ」と決めている人がいます。相手がわざと並べ方をくずすような札を送ってきても、迷わず置けます。
- **すきまの詰め方。** 自陣の札が減ってきたら、札を一段下げたり、左右の枚数をそろえたりする人が多いです。札を自分の近くに、相手からは遠くに保てます。

# どこまで固定する？

定位置をどこまで固定するかも、人によって考えが違います。

- **ほぼ固定。** 初心者にはみんな同じ定位置を教えて、慣れたら少しずつ変えていく会もあります。決まった並べ方は覚えるのも並べるのも速く、手の動きも早く身につきます。
- **基本形だけ。** 基本の形は持ちつつ、どこにでも置けるように練習する人もいます。試合中はどうせ札が動くので、思わぬ場所に札が来ても遅れないようにするためです。
- **ほとんど決めない。** トップ選手の中には、定位置をほとんど持たない人もいます。どんな並びからでも勝てる、という自信があるからです。

**はじめのうちは：** まず一つの並べ方を数週間続けてみましょう。手が出しにくい場所の札など、同じ失敗が続くときは、一度に一つずつ変えていきます。

>{.tobi} トップ選手でも意見はバラバラなんだ。キミの考えも大事にしてね！

# 自分の定位置を作る

いちばんよい定位置は、がんばらなくても覚えていられて、すばやく取れる並べ方です。作り方の一例を紹介します。

1. まずは基本から。一字決まりは下段、決まり字の長い札は端、上段は少なめに。
2. 友札をどうするか決めます。
3. 決まり字を小さく口にしながら何度も並べ、1分以内で並べられるようにします。
4. 自分を試します。このアプリの定位置練習では、並べた札が裏返り、読まれた札を一枚ずつ探します。
5. 試合で使ってみて、一度に一つずつ直していきます。

>{.tobi pose=waving} 自分の札に、自分の並べ方。畳の上で会おうね！
