# 百人一首ってなに？ | A hundred poems

百人一首は、百人の歌人の歌を一首ずつ集めたものです。いまから800年ほど前、藤原定家という歌人が選びました。

歌はどれも5・7・5・7・7の31音。前半の5・7・5を上の句、後半の7・7を下の句といいます。

![黒が上の句、ピンクが下の句。](assets/artworks/articles/karuta_poem_halves.webp)

お正月に家族で遊ぶ人も多いですね。それをスポーツにしたのが競技かるた。二人が向かい合って座り、読まれた歌の札を相手より先に取り合います。

# 読手と二種類の札 | The reader and two kinds of cards

試合には読手（どくしゅ）がいます。読手は勝負には加わらず、歌をバラバラの順番で一首ずつ読み上げます。

札は二種類で、それぞれ100枚。読み札には歌がまるごと書いてあり、読手だけが使います。取り札には下の句だけがひらがなで書いてあり、これを畳に並べます。

![読手が読む読み札と、キミが取る取り札。](assets/artworks/articles/karuta_two_cards.webp)

>{.tobi pose=pointing} 歌の始まりを聞いて、終わりが書かれた札を取る。おもしろいでしょ？

# 試合の流れ | How a match goes

1. 取り札100枚を裏にして混ぜ、25枚ずつ取ります。残りの50枚は使いません。
2. 自分の25枚を、自分の前に3段に並べます。ここが自陣。向かいにある相手の陣が敵陣です。
3. 並べたら15分の暗記時間。両方の陣のどこに何があるかを覚えます。
4. 読手は最初に、百人一首に入っていない序歌を読みます。そのあと、いよいよ本番です。
5. 歌が読まれたら、その札に相手より先に触れたほうが取り。札はどちらの陣にあってもかまいません。手で払って場の外に出してもOKです。
6. 敵陣の札を取ったら、自陣の札を1枚、相手に送ります。
7. 先に自陣の札がなくなったほうの勝ち！

![上が敵陣、下が自陣。ピンクの札がいま読まれた札。](assets/artworks/articles/karuta_field.webp)

>{.tobi pose=relaxed} 15分も暗記するの？そう、強い人は50枚ぜんぶの場所を覚えてるんだ。

# お手つき | Faults

使わなかった50枚も、読手は読みます。これを空札（からふだ）といいます。空札が読まれたときに場の札に触れると、お手つきです。

読まれた札が自陣にあるのに敵陣の札に触れたら、お手つき。その逆も同じです。正しい陣の別の札に触れただけなら、お手つきにはなりません。

お手つきをすると、相手から札を1枚送られます。速さだけでなく、ぐっと待つ力も大事です。

>{.tobi pose=shocked} あっ、また空札でお手つきしちゃった！

# 決まり字 | Kimariji

ここがいちばん大事なところ。歌を最後まで聞く必要はありません。最初の何音かで、どの札かがわかります。この音を決まり字といいます。

## 一字決まり

最初の音がほかのどの歌ともかぶらない歌が7首あります。1音目で取れる札で、「{むすめふさほせ}」と覚えます。

![](assets/artworks/articles/karuta_one_sound_{{ "romaji" if env.romaji_mode else "hiragana" }}.webp)

## 同じ音で始まる歌

多くの歌は、始まりの音がほかの歌と同じです。たとえば「{はるすぎて}」と「{はるのよの}」。どちらも「{はる}」で始まるので、3音目まで聞かないとわかりません。

![赤い音で決まる。どちらも3字決まりです。](assets/artworks/articles/karuta_kimariji_long_{{ "romaji" if env.romaji_mode else "hiragana" }}.webp)

## 決まり字は変わる

札は一度しか読まれません。「{はるすぎて}」が読まれたあと、「{はる}」で始まる札は「{はるのよの}」だけ。もう「{はる}」の2音で取れる、2字決まりの札に変わったのです。

![1枚読まれたから、2音で決まる。](assets/artworks/articles/karuta_kimariji_change_{{ "romaji" if env.romaji_mode else "hiragana" }}.ja.webp)

いちばん長いのは6字決まり。「{あさぼらけ}」「{わたのはら}」「{きみがため}」で始まる歌は2首ずつあって、6音目でやっと決まります。

>{.tobi pose=fired} 決まり字こそ、かるたの心臓。しっかり覚えれば、歌が終わる前に手が動くよ！

# 札飛ばしでできること | How Fudatobashi helps

このアプリは、かるたでいちばん大事なところを鍛えます。札が出たら決まり字を言って、できるだけ速くスワイプ。1枚ごとにタイムを計ります。

旅では新しい札が少しずつ増え、忘れかけた札がちょうどいいころに戻ってきます。100枚覚えたら卒業試験。合格するとランク戦が開き、速さでランクが決まります。

>{.tobi pose=cheering} ボクがずっと一緒だよ。修行で待ってるね！
